Legacy Deck Packages

New Deck starts with 5 complete basic-class progression packages so the Legacy Deck is never underfilled by default. Change a Hero progression to swap all 4 package cards automatically. Legacy eligibility follows class family. Same-family Hero variants are legal when distinct. Each Legacy Card may appear only once.
