# Grandis Legacy Deck Builder v1.13

## Style 2
- Main Deck cutting workspace capacity is 80 cards.
- Legal deck size remains exactly 60 cards.
- Counter remains `XX / 60`; e.g. `72 / 60`.
- 61–80 cards are invalid and Export is disabled.
- The 81st card is rejected.
- Imports above 80 cards are rejected.
- Hover/focus on `Skills XX` shows Skill counts by class, maximum 3 classes.
- Tooltip is hidden whenever `Skills XX` is not hovered/focused.
- Versioned Style 2 runtime assets prevent stale cached 60-card behavior.

## Preserved
- Style 1 behavior is unchanged.
- v1.11 navigation behavior is preserved.
