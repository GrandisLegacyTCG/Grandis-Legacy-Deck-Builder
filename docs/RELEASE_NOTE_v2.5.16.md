# Grandis Legacy PvP v2.5.16 — Release Note

## UI branding change
- Browser tab title is now exactly `Grandis Legacy PvP`.
- The browser tab no longer shows `Railway`.
- The browser tab no longer shows an application version number.
- Public-facing PvP version labels use `Grandis Legacy PvP` rather than the old provider-specific name.

## Preserved
Gameplay, runtime/card data, legality, network/server authority, lobby deck privacy, Authorized Observer, Deck Builder v1.14, and battlefield presentation are unchanged.
