# Grandis Legacy Deck Builder v1.28 — 2026-09-04

- Main Deck save/export is no longer restricted to 50 or 60 cards.
- Style 1 can build and export above 60 cards; there is no Main Deck size gate.
- Style 2 keeps its existing 80-card cutting/workspace ceiling but may export at any count within that workspace.
- Normal Main Deck cards remain maximum 3 copies per card.
- Ultimate remains maximum 1 copy per card.
- Match legality is intentionally enforced by VS AI and PvP, not by Deck Builder Main Deck size.
- Source Stack v1.7.3 and Starter60 v1.4 are unchanged.
