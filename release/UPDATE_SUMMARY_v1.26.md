# Deck Builder v1.26 Update Summary

## Scope
Deck construction/export legality only. No gameplay/card-effect authority changes.

## Legal deck sizes
- Valid Main Deck: 50 cards or 60 cards.
- 51–59 and every other size are invalid for export/save.
- Style 1 editing maximum remains 60 cards.
- Style 2 editing workspace remains 80 cards.

## Copy limits
- Normal card: max 3.
- Ultimate: max 1.

Both Style 1 and Style 2 validation/export use the same size contract.
