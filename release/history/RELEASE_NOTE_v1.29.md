# Grandis Legacy Deck Builder v1.29 — 2026-09-05

- Style 1 start flow is now split evenly into **Blank Deck** and **Import Deck**.
- Import Deck opens a local JSON file picker directly from the device and loads the selected Grandis Legacy deck into the workspace.
- Import does not require exactly 60 Main Deck cards. Deck Builder remains a flexible construction workspace.
- Normal cards remain maximum 3 copies per card; Ultimate remains maximum 1 copy per card.
- Existing Style 2 workspace behavior is preserved.
- Match legality remains enforced by VS AI / PvP, not by Deck Builder save/export size.
